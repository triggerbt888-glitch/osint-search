# SearXNG-контейнер для OSINT_AGENT — безлимитный поиск с JSON API.

Один и тот же `Dockerfile` + `settings.yml` работает на любом Docker-хостинге:

- **Render (free)** — основной бесплатный способ без карты,
  пошагово в DEPLOY.md корня репо, раздел «Вариант B»;
- свой сервер / VPS / домашний ПК — через `docker-compose.yml` из корня репо;
- любая другая Docker-платформа — укажи Root Directory на эту папку.

# Что внутри

- официальный образ `searxng/searxng`;
- на Render добавь переменную `SEARXNG_BIND_ADDRESS=0.0.0.0:10000`
  (10000 — стандартный порт Render); без неё образ слушает 8080;
- `settings.yml`: JSON API включён (`search.formats: [html, json]`),
  лимитер выключен — агент дергает поиск без капч и квот.

# Проверка после запуска

```
http://АДРЕС/search?q=test&format=json
```
должен вернуть JSON с результатами.

⚠️ Адрес поиска — фактически твой приватный ключ: SearXNG не умеет
API-ключей, поэтому просто не публикуй ссылку.
